## 게임 소개

Save The World는 6·25 전쟁유공자의 삶을 회고하는 스토리 중심 포인트 앤 클릭 게임입니다.

플레이어는 1인칭 시점에서 방을 탐색하고 아이템을 수집·사용하며, 여러 미니게임과 회상 장면을 통해 이야기를 따라갑니다. 탐색과 퍼즐, 대화 및 비주얼 연출을 연결해 인물의 삶을 경험하도록 구성했습니다.
